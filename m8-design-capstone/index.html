    M8 design capstone¶

    Status: Experimental/live-only.

    This stable page is a compatibility route. The decision questions, current blockers, authority boundary, and acceptance evidence now live in the M8 harness-evolution design brief.

    The deterministic example is implemented at examples/research/harness_evolution/; the retained failed capture and remaining live-validation gate are recorded in the design brief.

    The execution decision is fixed by the user-owned SDK boundary: the flagship takes an injected callable, CI uses a deterministic fixture-backed SDK client, and an opt-in maintainer driver uses the same boundary for an authorized live run. That one sanitized capture must retain failures and regressions honestly. External evaluation, equal budgets, mutation validation, and promotion remain outside user SDK authority.
