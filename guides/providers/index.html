    User-owned SDK integration¶

    The parser quickstart uses a model to propose source; the routing quickstart also calls a model while evaluating prompts. Both use ordinary Python callables. Meta-Evolve owns the evaluated loop and history. The example owns SDK installation, credentials, requests, response decoding, and usage reporting.

    Start with the parser, then routing¶

    Use Python 3.12+ on macOS or Linux. Download either the parser bundle or routing bundle into your working folder, along with the source package from this documentation build. For the parser:

    python3 -m venv .venv
. .venv/bin/activate
python -m pip install ./meta-evolve.zip
python -m zipfile -e parser.zip .
python parser.py --dry-run
python -m pip install openai
export OPENAI_API_KEY="your-api-key"
python parser.py --run ./runs/parser-01
python parser.py --inspect ./runs/parser-01

    For routing, extract prompt.zip instead and use prompt.py with a new directory. Its dry run previews cases; measuring accuracy requires model calls. Each bundle has exactly the lesson script, cases, and openai_client.py. No repository checkout or provider adapter is required. Full on-page explanations and source: parser, then routing.

    Configure and enforce requests¶

    Both lessons use gpt-5.4-mini-2026-03-17 by default, overridden by OPENAI_MODEL. The shared wrapper enforces a 120-second SDK request timeout, no automatic retries, 4,096 output tokens, and reasoning effort none. The timeout is not a hard total wall-clock deadline. Actual declarations are saved with the experiment; changing model or wrapper configuration changes experiment identity.

    The parser permits up to three rewrite requests and grades in Python. Routing permits up to 163 development requests (40 seed responses plus three rounds of one rewrite and 40 responses), then 12 separate final responses. Early stopping can reduce these counts. The candidate cannot change these controls.

    Complete example-local SDK wrapper
    openai_client.py
    """Example-owned Responses integration with optional user-owned cost reporting."""

from dataclasses import dataclass, replace
from decimal import Decimal, ROUND_CEILING, localcontext
from importlib.metadata import version
import os
import time
from typing import Callable, Literal

import meta_evolve as meta
from meta_evolve.domain import InvalidOutput
from meta_evolve.errors import ExecutionAccountingUnknown

DEFAULT_MODEL = "gpt-5.4-mini-2026-03-17"


@dataclass(frozen=True)
class CostReport:
    usd: Decimal
    kind: Literal["estimated", "billed"]
    source: str

    def __post_init__(self):
        if not isinstance(self.usd, Decimal) or not self.usd.is_finite() or self.usd < 0:
            raise ValueError("usd must be a finite nonnegative Decimal")
        if self.kind not in ("estimated", "billed") or not isinstance(self.source, str) or not self.source.strip():
            raise ValueError("report an estimated or billed amount with its source")

    @property
    def micros(self):
        with localcontext() as context:
            context.prec = max(28, len(self.usd.as_tuple().digits) + 6)
            return int((self.usd * 1_000_000).to_integral_value(rounding=ROUND_CEILING))


CostReporter = Callable[[object], CostReport | None]


def configuration():
    return {
        "model": os.environ.get("OPENAI_MODEL", DEFAULT_MODEL),
        "endpoint": "https://api.openai.com/v1", "api": "responses",
        "timeout_seconds": 120, "max_retries": 0,
        "max_output_tokens": 4096, "reasoning_effort": "none",
        "store": False, "wrapper_revision": "2", "cost_reporter_id": None,
    }


def decode_response(response, *, elapsed, cost_reporter: CostReporter | None = None):
    """Keep provider tokens, optional billed spend, and labeled cost evidence.

    Run the callback once, including for incomplete responses. A failed cost
    lookup leaves spend unknown and records its error without losing the model
    result. Missing token accounting still raises rather than fabricating zero.
    """
    evidence = []
    spend = None
    if cost_reporter is not None:
        try:
            report = cost_reporter(response)
            if report is not None:
                if not isinstance(report, CostReport):
                    raise TypeError("cost_reporter must return CostReport or None")
                evidence.append(meta.EvidenceDraft(kind="cost-report", data={
                    "usd": str(report.usd), "micros": report.micros,
                    "kind": report.kind, "source": report.source,
                }))
                if report.kind == "billed":
                    spend = report.micros
        except Exception as error:
            evidence.append(meta.EvidenceDraft(kind="cost-reporting-failure", data={
                "exception_type": type(error).__name__,
                "message": "Cost reporter failed; billed spend remains unknown.",
            }))
    usage = getattr(response, "usage", None)
    input_tokens = getattr(usage, "input_tokens", None)
    output_tokens = getattr(usage, "output_tokens", None)
    if any(type(value) is not int or value < 0 for value in (input_tokens, output_tokens)):
        error = ExecutionAccountingUnknown("Response lacks required token accounting.")
        error.receipt = {
            "response_id": getattr(response, "id", None),
            "input_tokens": input_tokens, "output_tokens": output_tokens,
            "charged_micros": spend, "wall_seconds": elapsed,
            "cost_evidence": [dict(item.data) for item in evidence],
        }
        raise error
    measured = meta.Usage(
        tokens=input_tokens + output_tokens, spend_micros=spend, wall_seconds=elapsed,
    )
    text = getattr(response, "output_text", None)
    evidence.append(meta.EvidenceDraft(kind="openai-response", data={
        "response_id": response.id, "model": response.model,
        "status": response.status, "output_text": text,
        "input_tokens": input_tokens, "output_tokens": output_tokens,
        "charged_micros": spend,
    }))
    if response.status != "completed" or not isinstance(text, str) or not text.strip():
        return meta.ProposalResult(
            failure=InvalidOutput(message="model returned empty or incomplete text"),
            usage=measured, evidence=tuple(evidence),
        )
    return meta.ProposalResult(candidate=text, usage=measured, evidence=tuple(evidence))


@dataclass
class OpenAIClient:
    """The lesson knows generate() and configuration; SDK types stay here."""

    sdk: object
    configuration: dict
    cost_reporter: CostReporter | None = None

    def __post_init__(self):
        reporter_id = self.configuration.get("cost_reporter_id")
        if self.cost_reporter is not None and (
            not callable(self.cost_reporter) or not isinstance(reporter_id, str) or not reporter_id.strip()
        ):
            raise ValueError("a callable cost reporter needs a recorded cost_reporter_id")

    @classmethod
    def from_environment(cls, *, cost_reporter=None, cost_reporter_id=None):
        if not os.environ.get("OPENAI_API_KEY", "").strip():
            raise meta.CapabilityError("Set OPENAI_API_KEY before requesting a live run.")
        if cost_reporter is not None and (
            not callable(cost_reporter) or not isinstance(cost_reporter_id, str) or not cost_reporter_id.strip()
        ):
            raise ValueError("supply a callable cost_reporter and its cost_reporter_id")
        try:
            from openai import OpenAI
        except ImportError as error:
            raise meta.CapabilityError("Install the SDK: python -m pip install openai") from error
        settings = configuration() | {
            "sdk_version": version("openai"), "cost_reporter_id": cost_reporter_id,
        }
        sdk = OpenAI(api_key=os.environ["OPENAI_API_KEY"], base_url=settings["endpoint"],
                     timeout=settings["timeout_seconds"], max_retries=settings["max_retries"])
        return cls(sdk, settings, cost_reporter)

    def generate(self, *, instructions, input):
        settings = self.configuration
        started = time.monotonic()
        try:
            response = self.sdk.with_options(
                timeout=settings["timeout_seconds"], max_retries=settings["max_retries"],
            ).responses.create(
                model=settings["model"], instructions=instructions, input=input,
                max_output_tokens=settings["max_output_tokens"],
                reasoning={"effort": settings["reasoning_effort"]}, store=settings["store"],
            )
        except ExecutionAccountingUnknown:
            raise
        except Exception as cause:
            raise ExecutionAccountingUnknown(
                "Request failed after dispatch; token accounting is unavailable."
            ) from cause
        try:
            result = decode_response(response, elapsed=0, cost_reporter=self.cost_reporter)
        except ExecutionAccountingUnknown as error:
            error.receipt["wall_seconds"] = time.monotonic() - started
            raise
        # Include a cost lookup's elapsed time in the component's usage too.
        return replace(result, usage=replace(result.usage, wall_seconds=time.monotonic() - started))

    def __enter__(self):
        return self

    def __exit__(self, *exc):
        self.sdk.close()

    The wrapper returns ProposalResult with text or a typed failure, known usage, and response evidence. Its generate(instructions=..., input=...) method is example-local, not a core interface. Your own SDK can use the same callable seam.

    Keep accounting and history¶

    Total tokens are input plus output; cached-input tokens are already included in input. Without an exact billed receipt, spend is unknown. A monetary ceiling stops further work when spend cannot be verified; it does not reserve funds or impose a hard provider-side cap. Estimates belong in evidence.

    --inspect reads saved observations without repeating requests. Reopening does not make local closures resumable, and a later model execution need not reproduce recorded answers. The parser's optional cost callback is described on its lesson page.

    The extraction case study retains its distinct structured-response integration: respond(prompt, notes) and rewrite(parent, report) compose through the same boundary. Its fixtures and synthetic accounting are case-study evidence, not live performance. Source-tree edits and command grading belong to agent test-repair.

    Return a typed result¶

    Use ProposalResult when the wrapper has more to report. This and the my_sdk tool example below are user-supplied SDK pseudocode:

    def propose(parent, context):
    response = my_sdk.generate_structured(input=parent)
    return meta.ProposalResult(
        candidate=response.artifact,
        usage=meta.Usage(
            tokens=response.input_tokens + response.output_tokens,
            # Charged spend is shared usage; estimates stay evidence.
            spend_micros=response.charged_micros,
            wall_seconds=response.elapsed_seconds,
        ),
        metadata={"model": response.model},
        evidence=(
            meta.EvidenceDraft(
                kind="sdk-response",
                data={"estimated_cost": response.estimated_cost, "raw": response.raw},
            ),
        ),
    )

    Total tokens, charged monetary spend, and elapsed time enter shared Usage. Model identity, estimated cost, granular token categories, and raw provider telemetry belong in evidence or metadata: only a figure the provider actually billed may become spend_micros. When no bill is available, explicitly report spend_micros=None. Keep input and output tokens; cached input and reasoning output are generally subsets, so use the SDK's documented totals without counting those subsets twice. A valid response remains usable. Unknown spend propagates through sums and stops further work under a monetary ceiling, as described in Money.

    When a paid call fails, a wrapper has three cases, and the last is the one that is easy to miss:

    1. tokens and other required measures are known — return a typed failure carrying that usage, with unknown billed spend represented by None;
    2. the failure happened before any paid work — return a typed failure with zero usage;
    3. work may have started and required measures such as tokens are unavailable — raise ExecutionAccountingUnknown.

    The names come from two submodules:

    from meta_evolve.domain import InvalidOutput          # and the other failures
from meta_evolve.errors import ExecutionAccountingUnknown

    Known spend_micros is an integer, so convert before reporting — a float raises. Round up, so the framework never under-reports a charge, and keep the raw provider figure in evidence as provenance.

    Convert through Decimal, not by multiplying the float. Binary floats do not hold decimal amounts exactly, and the error goes the wrong way at exact micro boundaries: 0.000123 * 1_000_000 evaluates to 123.00000000000001, so a math.ceil of that produces 124 micro-USD for an amount that is exactly 123. Over-reporting money is a defect, not a safe direction.

    from decimal import Decimal, ROUND_CEILING, InvalidOperation, localcontext

def charged_micros(cost_usd: object) -> int | None:
    """Exact micro-USD, rounded up, or an explicitly unknown amount."""

    try:
        # str() first: it yields the shortest decimal that round-trips the
        # value, so Decimal("0.000123") -- not the binary approximation.
        amount = cost_usd if isinstance(cost_usd, Decimal) else Decimal(str(cost_usd))
    except (InvalidOperation, ValueError, TypeError):
        return None
    if not amount.is_finite() or amount < 0:
        return None
    with localcontext() as context:
        context.prec = max(28, len(amount.as_tuple().digits) + 6)
        return int((amount * 1_000_000).to_integral_value(rounding=ROUND_CEILING))

    For an unreadable amount, retain a cost-reporting failure in evidence and report unknown spend. Missing token accounting still requires the case-3 escape.

    Decode the amount exactly, before it becomes a float. The conversion above is only as exact as its input, and str(float) recovers just the digits the float kept — by then 0.0001230000000000000000001 is already 0.000123, and rounding up gives 123 micro-USD instead of 124. A float cannot be repaired after the fact. So read the charge from the raw body:

    body = json.loads(response.text, parse_float=Decimal)
micros = charged_micros((body.get("usage") or {}).get("cost"))

    If your client hands you a decoded object rather than text, take the amount from somewhere exact — a Decimal, an integer, or a decimal string — rather than a float that has already been rounded.

    The duration-parser lesson supplies an optional cost_reporter(response) callback on its example-owned SDK wrapper. It accepts a function or bound method, so users can calculate a token-price estimate or call their own billing API. Its CostReport explicitly labels estimated versus billed, retains the source, and records the reporter's version in configuration. These are example types; core needs only ordinary ProposalResult/EvaluationResult, Usage, and evidence. A committed report is read back during inspection, without invoking the callback again.

    Never raise an ordinary exception after billing, and never return a bare Failure: both paths reach the adapter with no usage field, so the framework records zero and the charge is lost. This is a framework guarantee about those channels, not something conformance can detect on your behalf.

    Trial and evaluation counts are coordinator-owned; reporting either at the proposer boundary produces typed InvalidOutput. The meeting-notes evaluator rejects response-wrapper counts as a failed measurement, retaining known usage.

    At the proposer boundary, ordinary SDK exceptions become ProposerFailure. Framework failures about durable state, accounting, or run capability escape unchanged: EventStreamConflict, DurableCorruption, InvalidSearchHistory, ExperienceStoreUnavailable, ExecutionAccountingUnknown, and CapabilityError.

    Give an SDK audited pull tools¶

    When an SDK supports custom tools, register a user-owned handler that delegates to context.experience:

    used = []

def search_experience(arguments):
    if context.experience is None:
        raise meta.ExperienceAccessDenied("pull access was not granted")
    observation = context.experience.search(**arguments)
    used.extend(record.ref for record in observation.records)
    return observation

response = my_sdk.run(tools={"search_experience": search_experience})
return meta.ProposalResult(
    candidate=response.artifact,
    derived_from=tuple(dict.fromkeys(used)),
)

    The exact observation API is defined by ExperienceReader. The callback may run in process, or a user-owned RPC service may forward each request to this scoped handler and return its result. The RPC service must not cache or broaden the reader capability. Meta-Evolve adds no generic tool server or agent process.

    Access denial, exhaustion, audit-store failure, and unknown accounting retain their normal semantics because the SDK tool calls the authoritative reader. SDKs without custom-tool support can receive pushed context.bundle data, but that is context injection rather than agent-directed pull.

    The credential-free 06_user_owned_sdk example contains a complete deterministic fake SDK and audited tool callback. An acceptance-gated milestone may own an opt-in real-client experiment, as M8 does for harness validation. There is no generic provider smoke directory: a live script must serve a current gate, add no package dependency, and retain its single authorized outcome honestly.

    Authority and reproducibility¶

    The wrapper may propose candidate content. It cannot choose the evaluator, change the run budget, grant itself experience, edit audit history, or promote a result. External evaluation and durable storage remain the sources of score, accounting, and lineage truth.

    Committed requests, evidence, usage, failures, and artifacts support inspection and replay. Meta-Evolve does not claim that a later external SDK call will regenerate byte-identical output.
