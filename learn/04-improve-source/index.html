    Improve source against an independent grader¶

    Both examples on this page use handwritten repairs and real subprocess graders, with no model calls or credentials.

    A source file can be the candidate too. This complete example repairs a small clamp() function against three independent checks. Copy it into a Python file with meta_evolve installed; the candidate and grader are both inline.

    Propose a patch and measure it¶

    SourceTree stores immutable source. PatchProposer applies a TextPatch in a private mutable workspace and captures an immutable successor. The patch names one file, its exact expected bytes, and the replacement. CommandEvaluator independently materializes each candidate and runs the evaluator-owned grader.

    The fixed repair is handwritten. The example demonstrates the API and evaluation boundary, not a model discovering a repair.

    import sys
import meta_evolve as meta

BAD = "def clamp(value, low, high):\n    return value\n"
FIXED = "def clamp(value, low, high):\n    return max(low, min(value, high))\n"
seed = meta.SourceTree({"clamp.py": BAD})


def repair(tree, context):
    return meta.TextPatch(path="clamp.py", expected=tree["clamp.py"], replacement=FIXED)


# The grader belongs to the evaluator, outside the candidate's source tree.
GRADER = """
import runpy
try:
    clamp = runpy.run_path("clamp.py")["clamp"]
    passed = all(clamp(value, 0, 10) == expected
                 for value, expected in ((-5, 0), (5, 5), (15, 10)))
except Exception:
    passed = False
raise SystemExit(0 if passed else 1)
"""
evaluator = meta.CommandEvaluator(
    command=meta.ProcessSpec(argv=(sys.executable, "-c", GRADER)),
    environment=meta.EvaluationEnvironment(name="clamp-checks", version="1"),
)
result = meta.run(meta.Experiment(
    seed=seed,
    task=meta.Task(artifact=meta.SourceTree, evaluator=evaluator),
    proposer=meta.PatchProposer(repair),
    search=meta.Greedy(max_trials=1),
))
print("Scores:", [t.metrics["score"] for t in result.trials()])
print("Parent unchanged:", seed["clamp.py"] == BAD)
print("Selected source:")
print(result.best().value["clamp.py"], end="")
print("Usage:", result.usage().trials, result.usage().evaluations)
# Output:
# Scores: [0.0, 1.0]
# Parent unchanged: True
# Selected source:
# def clamp(value, low, high):
#     return max(low, min(value, high))
# Usage: 1 2

    The grader checks all three inputs. Exit 0 passes the suite; exit 1 is a valid failing measurement. The poor candidate remains a measured result with score 0.0. Candidate load or execution errors also fail this particular grader's suite.

    The evaluator records process evidence alongside each measurement. trials() retains both candidates, and lineage() follows the selected source's parents. A patch whose expected bytes do not match produces InvalidOutput; an evaluator infrastructure failure produces EvaluatorFailure. Neither becomes a low score.

    The proposer edits source, not the grader, budget, or promotion rules. The local subprocess is a development execution boundary, not a sandbox for hostile code. These three selection checks are not an untouched final test split, and passing them establishes nothing about other functions.

    Change and predict¶

    Set FIXED = BAD and rerun the complete example. Predict Scores: [0.0, 0.0]: a valid patch can produce source that still fails evaluation. Selection does not deploy the result; use independent checks before promotion.

    Repair booking ranges¶

    A booking tool should merge touching ranges: (9, 10) and (10, 11) must become (9, 11). The maintained agent_test_repair application starts with source that merges overlaps but leaves touching bookings separate. Its fixture replaces start < merged[-1][1] with start <= merged[-1][1].

    Setup and run¶

    Use Python 3.12+ on macOS or Linux with subprocess execution, Git, and uv:

    git clone https://github.com/sentient-xyz/meta-evolve.git
cd meta-evolve
uv sync --locked

    Run from the repository root. These first output lines are checked against the actual command; it also prints the selected source and evaluations: 2.

    uv run python examples/agents/agent_test_repair/main.py
    Output
    scores: [0.0, 1.0]
grader passed: True

    The actual declaration¶

    This function comes from the maintained application:

    main.py · repair_intervals
    def repair_intervals(
    build_agent: Callable[[str], Proposer],
    *,
    grader: Path = GRADER,
    random_seed: int = 0,
) -> meta.Run:
    """Run the repair loop with one agent factory and one grader.

    Both are injectable so the same loop serves every caller: ``main`` passes
    the committed fixture, a live run passes a factory that wraps a real model
    SDK, and the test suite passes counting fixtures and a deliberately broken
    grader. Nothing else about the task, seed, search, or budget changes.
    """

    experiment = meta.Experiment(
        task=grading_task(grader),
        seed=meta.load_source_tree(CANDIDATE),
        proposer=build_agent(INSTRUCTIONS),
        search=meta.Greedy(max_trials=MAX_TRIALS),
        random_seed=random_seed,
    )
    return meta.run(experiment)

    CANDIDATE names the directory containing only intervals.py. INSTRUCTIONS describes the failing case; build_agent returns a source-tree proposer. The fixture already knows the fix. grading_task owns the external runner, grader, score threshold of 1.0, and budget of at most two revisions and three evaluations. Greedy stops after the first passing revision. No context policy is configured. The candidate cannot edit the grader or expand these limits.

    The independent grader covers overlapping, disjoint, touching, contained, and unsorted ranges. Its runner interprets exit 0 as score 1.0, exit 1 as score 0.0, and a missing/crashing grader as EvaluatorFailure with no score. A candidate that cannot import fails its tests; it is distinct from a broken grader.

    These cases guide selection and are not an untouched final split. The local process boundary is not hostile-code isolation. Passing tests here demonstrates this repair, not model ability or correctness for an arbitrary repository.

    Change and predict¶

    In a scratch checkout, make the replacement string in fixture_agent identical to its original start < merged[-1][1]. Rerun: predict scores: [0.0], grader passed: False, and evaluations: 3. Both allowed revisions are tried, but the printed scores follow only the selected artifact's lineage: the seed remains selected because neither revision improves it. All three evaluations remain in result.trials(). Restore the fixture afterward.

    For your own task, replace the candidate files, instruction brief, and independent grader. Supply an SDK-backed callable factory to repair_intervals to replace the fixture; keep evaluation and permissions outside candidate authority.

    Complete booking-range source¶

    candidate/intervals.py 
    """Collapse booking ranges into the blocks an operator actually sees.

A range is an inclusive ``(start, end)`` pair. Two ranges belong to the same
block when they overlap *or* touch: ``(9, 10)`` and ``(10, 11)`` describe one
uninterrupted block from 9 to 11 and must come back as ``(9, 11)``.
"""


def merge_intervals(intervals):
    """Return the fewest non-touching blocks covering ``intervals``, in order."""

    merged = []
    for start, end in sorted(intervals):
        if merged and start < merged[-1][1]:
            last_start, last_end = merged[-1]
            merged[-1] = (last_start, max(last_end, end))
        else:
            merged.append((start, end))
    return merged
    grader.py 
    """Evaluator-owned checks for the materialized interval candidate."""

from __future__ import annotations

import importlib.util
import traceback
from pathlib import Path


# Overlapping and disjoint ranges are the cases anyone writes first, and the
# shipped code gets both right. Only the touching ones — where a block ends
# exactly where the next begins — catch the defect.
CASES: tuple[tuple[list[tuple[int, int]], list[tuple[int, int]]], ...] = (
    ([], []),
    ([(1, 4)], [(1, 4)]),
    ([(1, 3), (2, 4)], [(1, 4)]),
    ([(1, 5), (2, 3)], [(1, 5)]),
    ([(1, 2), (4, 5)], [(1, 2), (4, 5)]),
    ([(5, 6), (1, 2)], [(1, 2), (5, 6)]),
    ([(1, 2), (2, 3)], [(1, 3)]),
    ([(1, 2), (2, 3), (3, 4), (6, 7)], [(1, 4), (6, 7)]),
)


def _mismatch(merge, intervals, expected) -> str | None:
    actual = merge(list(intervals))
    # The block type is the candidate's call; the block contents are not.
    if [tuple(block) for block in actual] == expected:
        return None
    return f"merge_intervals({intervals!r}) returned {actual!r}, expected {expected!r}"


def grade(workspace: Path) -> tuple[bool, str]:
    """Anything the candidate causes — wrong answers, code that fails to
    load or run — is an ordinary failure. Only a grader-internal fault may
    escape as an exception, which the runner reports outside the pass/fail
    protocol.
    """

    try:
        candidate = workspace / "intervals.py"
        spec = importlib.util.spec_from_file_location("candidate_intervals", candidate)
        if spec is None or spec.loader is None:
            raise ImportError(f"cannot load candidate module: {candidate}")
        module = importlib.util.module_from_spec(spec)
        spec.loader.exec_module(module)
        merge = module.merge_intervals
        failures = [
            message
            for intervals, expected in CASES
            if (message := _mismatch(merge, intervals, expected)) is not None
        ]
    except Exception:
        return False, f"candidate failed to load or run:\n{traceback.format_exc()}"
    if failures:
        return False, "\n".join(failures)
    return True, f"all {len(CASES)} merge_intervals cases passed"
    main.py 
    """An injected proposer repairs a real bug; a grader subprocess decides.

The seed is a ``SourceTree`` holding a function whose documented contract and
shipped behaviour disagree on one character. The proposer is supplied by the
caller through the user-owned callable boundary: the committed script injects
a deterministic fixture, and a real SDK wrapper plugs into the same seam. The
evaluator is a *separate process* running an evaluator-owned grader the
proposer never sees, so the score is a verdict about the code rather than a
report from the thing being scored.

The grader obeys the fixed exit protocol: ``0`` passes, ``1`` is a rankable
failure with a failing score, and anything else is an ``EvaluatorFailure``.
That third code is the load-bearing one here. With an agent in the loop, a
grader that is itself broken must not quietly rank every attempt as bad work;
it must stop the run and say so.

Every piece is importable and injectable: ``repair_intervals`` takes the agent
factory and the grader path, so a deterministic test drives this same logic
through counting fixture proposers and a deliberately broken grader.
"""

from __future__ import annotations

import sys
from collections.abc import Callable
from pathlib import Path

import meta_evolve as meta
from meta_evolve.ports import Proposer


HERE = Path(__file__).parent
CANDIDATE = HERE / "candidate"
RUNNER = HERE / "run_grader.py"
GRADER = HERE / "grader.py"

AGENT_TIMEOUT_SECONDS = 120.0
# One proposal per trial, and the run stops early the moment the grader
# passes. The wall ceiling is sized for a live SDK wrapper whose sessions each
# stay inside AGENT_TIMEOUT_SECONDS, plus the grader subprocesses between
# them; the committed fixture never comes near it.
MAX_TRIALS = 2
BUDGET = meta.Budget(
    evaluations=MAX_TRIALS + 1,
    trials=MAX_TRIALS,
    wall_seconds=AGENT_TIMEOUT_SECONDS * (MAX_TRIALS + 1),
)

# What a developer is handed by CI: the failing case, not the fix. The repo
# states the contract in the module docstring; finding the one character that
# disagrees with it is the agent's job.
INSTRUCTIONS = (
    "The test suite for intervals.py fails one case: "
    "merge_intervals([(1, 2), (2, 3)]) returned [(1, 2), (2, 3)] where "
    "[(1, 3)] was expected. Read intervals.py, find why it disagrees with "
    "the contract it documents, and fix it. Change only intervals.py, and "
    "keep merge_intervals' name and signature."
)


def grading_task(grader: Path = GRADER) -> meta.Task:
    """Score candidates by running the grader in its own process.

    ``CommandEvaluator`` materializes each candidate tree into a fresh
    workspace and runs the fixed runner there. The grader lives outside
    ``candidate/``, so it is never part of any ``SourceTree`` a proposal
    could read or edit, and its exit code — not anything the candidate
    prints about itself — is what becomes the score.
    """

    return meta.Task(
        evaluator=meta.CommandEvaluator(
            command=meta.ProcessSpec(
                argv=(sys.executable, str(RUNNER), str(grader)),
                environment={"PYTHONDONTWRITEBYTECODE": "1"},
            ),
            environment=meta.EvaluationEnvironment(
                name="python-intervals-tests",
                version="1",
            ),
        ),
        artifact=meta.SourceTree,
        # Stop as soon as the grader passes: further attempts cost money and
        # cannot improve on a passing suite.
        objectives=(meta.Maximize("score", satisfy=1.0),),
        budget=BUDGET,
    )


def repair_intervals(
    build_agent: Callable[[str], Proposer],
    *,
    grader: Path = GRADER,
    random_seed: int = 0,
) -> meta.Run:
    """Run the repair loop with one agent factory and one grader.

    Both are injectable so the same loop serves every caller: ``main`` passes
    the committed fixture, a live run passes a factory that wraps a real model
    SDK, and the test suite passes counting fixtures and a deliberately broken
    grader. Nothing else about the task, seed, search, or budget changes.
    """

    experiment = meta.Experiment(
        task=grading_task(grader),
        seed=meta.load_source_tree(CANDIDATE),
        proposer=build_agent(INSTRUCTIONS),
        search=meta.Greedy(max_trials=MAX_TRIALS),
        random_seed=random_seed,
    )
    return meta.run(experiment)


def fixture_agent(_instructions: str) -> Proposer:
    """The committed proposer: a deterministic stand-in for an SDK wrapper.

    It occupies exactly the seat a user-owned SDK wrapper occupies — a factory
    that takes the instructions and returns an ordinary proposer callable —
    but it already knows the one-character repair, so the committed script
    runs offline, credential-free, and for free. It takes no shortcut past the
    evaluator: its candidate is scored by the same grader subprocess a live
    wrapper's would be, and the instructions it ignores are the ones a live
    wrapper would forward to its model.
    """

    def repair(tree: meta.SourceTree, _context) -> meta.SourceTree:
        return meta.SourceTree(
            {
                **tree,
                "intervals.py": tree["intervals.py"].replace(
                    "start < merged[-1][1]", "start <= merged[-1][1]"
                ),
            }
        )

    return repair


def main() -> None:
    """Run the loop with the fixture and print what the grader decided.

    Swap ``fixture_agent`` for your own factory to put a real agent in the
    loop; the printing below distinguishes "the best candidate scored X" from
    "nothing was scored at all", which is the difference the exit protocol
    exists to preserve.
    """

    result = repair_intervals(fixture_agent)
    try:
        trial = result.best_trial()
    except meta.NoSuccessfulEvaluation:
        # Not "every candidate is bad": no candidate was scored at all. Every
        # evaluation recorded a typed failure carrying no metric, so there is
        # nothing to rank -- a grader fault (exit 2) is the one this example
        # exists to show.
        print("no candidate scored: every evaluation failed before producing one")
        print(f"run {result.id.value} recorded why; the seed source is unchanged")
        raise SystemExit(1)
    print(f"scores: {[step.metrics['score'] for step in result.lineage()]}")
    print(f"grader passed: {trial.metrics['score'] == 1.0}")
    print(f"best source:\n{result.best().value['intervals.py']}")
    print(f"evaluations: {result.summary().evaluation_count}")


if __name__ == "__main__":
    main()
    run_grader.py 
    """Fixed grader runner: exit 0 pass, 1 rankable failure, other grader fault.

The runner loads the evaluator-owned grader named by ``argv[1]`` and grades
the current working directory — the materialized candidate workspace.
Anything the candidate causes is an ordinary exit ``1``; a missing, crashing,
or malformed grader exits ``2`` so it surfaces as an ``EvaluatorFailure``
instead of ranking every candidate as failing.
"""

import importlib.util
import sys
import traceback
from pathlib import Path

exit_code = 2
try:
    grader_path = Path(sys.argv[1])
    spec = importlib.util.spec_from_file_location("external_grader", grader_path)
    if spec is None or spec.loader is None:
        raise ImportError(f"cannot load external grader: {grader_path}")
    grader = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(grader)
    result = grader.grade(Path.cwd())
    if (
        not isinstance(result, tuple)
        or len(result) != 2
        or type(result[0]) is not bool
        or not isinstance(result[1], str)
    ):
        raise TypeError("grader must return tuple[bool, str]")
    print(result[1])
    exit_code = 0 if result[0] else 1
except BaseException:
    traceback.print_exc()
raise SystemExit(exit_code)
