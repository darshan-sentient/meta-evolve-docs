    Inspect results¶

    Status: Shipped.

    Continue with the preceding checklist program. Start with greedy_result.best().value: it is the checklist you can use. Then ask why it won. best_trial() attaches its measurement and evidence; lineage() follows the causal path from the seed. These views read the retained result.

    trials() includes attempts outside the winning path. In the BestOfN run, two equal-scoring proposals are measured but do not displace the winner. They remain visible. summary().usage counts work actually consumed, including the seed evaluation, while compare() checks compatible run declarations.

    uv run python examples/learn/checklist/_stories/search_story.py
    Output
    best(): ('outline', 'draft', 'review')
best_trial(): (3, 3)
trials(): (((), 'evaluated'), (('outline',), 'evaluated'), (('outline', 'draft'), 'evaluated'), (('outline', 'draft', 'review'), 'evaluated'))
lineage(): ((), ('outline',), ('outline', 'draft'), ('outline', 'draft', 'review'))
summary(): (3, Usage(evaluations=4, trials=3, tokens=0, spend_micros=0, wall_seconds=0.0))
compare(): Greedy
failure: ('trial_failed', 'InvalidOutput')
inspect(): rankable

    A failed proposal has no measurement; it is different from the valid seed’s poor score of zero. Run this small diagnostic companion to see both failures:

    """Distinguish a poor measurement from a failed measurement."""

import meta_evolve as meta


def broken_measurement(_completed):
    raise ValueError("The grader could not measure this candidate")


poor = meta.improve(seed=(), proposer=lambda value: value, evaluator=len, trials=0)
failed = meta.improve(
    seed=(), proposer=lambda value: value, evaluator=broken_measurement, trials=0,
)
print("poor score:", poor.best_trial().metrics["score"])
print("failed measurement:", type(failed.trials()[0].failure).__name__)
try:
    failed.best()
except meta.NoSuccessfulEvaluation:
    print("no winner:", failed.inspect().overview.rankability)


    uv run python examples/learn/checklist/_stories/failure_story.py
    Output
    poor score: 0
failed measurement: EvaluatorFailure
no winner: unrankable

    For failures, inspect() works even when best() cannot return a winner:

    for trial in result.trials():
    if trial.failure is not None:
        print(trial.state, trial.failure.kind, trial.failure.message)

report = result.inspect()
print(report.overview.lifecycle, report.overview.rankability)

    best() then raises NoSuccessfulEvaluation with the same direction: inspect trials() or inspect() for typed failures.
