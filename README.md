# Meta-Evolve docs

Published static documentation for [Meta-Evolve](https://github.com/sentient-xyz/meta-evolve).

Site: https://sentient-xyz.github.io/meta-evolve-docs/

This repository contains the built MkDocs site. Documentation source lives in
the main project. Build and validate it there, then publish the generated site
here. `.source-commit` records the exact source revision used for this publication.

`.publication-scope.json` records the build scope, generated file hashes,
verification, and previous publication commit. Older immutable support archives
are retained so previously downloaded notebooks can still fetch their dependencies.
