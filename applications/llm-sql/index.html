    Maximise LLM prompt-cache hits¶

    Evolve a published column-order algorithm so serialized table rows share a longer prompt-cache prefix. You supply the seed, evaluator, and proposer; meta.improve() scores rewrites and keeps the best measured program. Adapt the seed, model, and grader to another layout task.

    Status: Experimental/live-only. Scoring the seed needs no API key — that is the check that the wiring works. The improve loop needs OPENROUTER_API_KEY and makes model requests. Scoring all five tables can take several minutes per candidate. Three trials are enough to see the loop; they are not a paper reproduction.

    The concrete problem¶

    Rows of a table are serialized left-to-right and sent to an LLM. A row prefix that already appeared is served from the prompt cache. Column order decides how much you pay.

    col 1 col 2 col 3 col 4 col 5
    row n Just Mercy Drama Warner Bros. Fresh True
    row n+1 Just Mercy Drama Warner Bros. Rotten False

    Shared columns first: cache hit. Verdict first: the shared text is no longer a prefix, so none of it hits. The algorithm may reorder columns and rows. It may not change a cell.

    The seed is GRG from ADRS llm_sql. The score is 0.95 * mean(hit_rate) + 0.05 * (12 - min(12, mean(runtime))) / 12 over five tables. Hit rate dominates; runtime is a tiebreaker.

    Setup and run¶

    Python 3.12+. Open a fresh notebook and paste the blocks below in order, or open the reference notebook. Restart the kernel after install if asked. Scoring the seed needs no API key; the improve loop needs OPENROUTER_API_KEY.

    Install¶

    Paste into the first notebook cell.

    %pip install "pandas==2.2.3" "numpy<2.1" networkx "meta-evolve @ git+https://github.com/sentient-xyz/meta-evolve.git"

    Fetch the seed¶

    This sparse-clones the ADRS task and loads GRG as a Python source string. That string is the artifact Meta-Evolve will rewrite.

    import os, subprocess
from pathlib import Path

import pandas as pd
import meta_evolve as meta

assert pd.__version__.startswith("2.2"), pd.__version__

WORK = Path("adrs_llm_sql_run").resolve()
TASK = WORK / "adrs-upstream" / "openevolve" / "examples" / "ADRS" / "llm_sql"
WORK.mkdir(parents=True, exist_ok=True)

if not TASK.exists():
    subprocess.run(
        ["git", "clone", "--filter=blob:none", "--no-checkout",
         "https://github.com/UCB-ADRS/ADRS.git", str(WORK / "adrs-upstream")],
        check=True,
    )
    subprocess.run(
        ["git", "sparse-checkout", "set", "openevolve/examples/ADRS/llm_sql"],
        cwd=WORK / "adrs-upstream",
        check=True,
    )
    subprocess.run(["git", "checkout"], cwd=WORK / "adrs-upstream", check=True)

SEED = (TASK / "initial_program.py").read_text()
print(f"seed: {TASK / 'initial_program.py'} ({len(SEED)} chars)")

    Measure it¶

    The evaluator writes the candidate to a file and scores it in a subprocess, so a hang cannot take the notebook with it. It returns one number, combined_score. Run this before you set an API key: if the seed prints about 0.6961, the loop is wired correctly. The 4th digit can move with machine speed; hit rate is the stable part.

    If score_one.py is not next to the notebook, this cell downloads it. You can also save score_one.py yourself.

    import json, os, subprocess, sys
from pathlib import Path
from urllib.request import urlretrieve

GRADER = Path("score_one.py")
if not GRADER.exists():
    urlretrieve(
        "https://sentient-xyz.github.io/meta-evolve-docs/applications/llm-sql/score_one.py",
        GRADER,
    )

def evaluate(source):
    """Score one Evolved module. Returns combined_score, or raises on failure."""
    work = WORK / "candidates"
    work.mkdir(parents=True, exist_ok=True)
    program = work / "candidate.py"
    program.write_text(str(source))
    done = subprocess.run(
        [sys.executable, str(GRADER.resolve()), str(program)],
        cwd=str(WORK),
        env={**os.environ, "ADRS_TASK_DIR": str(TASK)},
        capture_output=True,
        text=True,
        timeout=900,
    )
    report = None
    for line in reversed(done.stdout.splitlines()):
        line = line.strip()
        if line.startswith("{"):
            report = json.loads(line)
            break
    if not report or not report.get("ok"):
        error = (report or {}).get("error") or done.stderr[-500:] or "score failed"
        raise RuntimeError(error)
    return report["combined_score"]

score = evaluate(SEED)
print(f"seed combined_score: {score:.4f}")
# Output:
# seed combined_score: 0.6961

    A crash, timeout, or shrink-the-text cheat raises. meta.improve() records that as an evaluator failure with no score, and search continues from the last good program.

    Propose a rewrite¶

    The proposer is an ordinary function: source in, source out. This one calls OpenRouter. Swap the URL, key, and model together to use another provider.

    import json, os, re, urllib.request

API_KEY = os.environ["OPENROUTER_API_KEY"]
MODEL = "anthropic/claude-sonnet-5"
SYSTEM = """You evolve a Python algorithm for the ADRS llm_sql task.
Reorder columns and rows only. Never change a cell.
Emit one module that defines class Evolved(Algorithm) with:
    def reorder(self, df, early_stop=0, row_stop=None, col_stop=None,
                col_merge=[], one_way_dep=[], distinct_value_threshold=0.8,
                parallel=True)
Import the base class with `from solver import Algorithm`.
Return only a ```python block."""

def propose(parent):
    payload = json.dumps({
        "model": MODEL,
        "messages": [
            {"role": "system", "content": SYSTEM},
            {"role": "user", "content": "Improve this Evolved algorithm.\n\n```python\n" + str(parent) + "\n```"},
        ],
    }).encode()
    request = urllib.request.Request(
        "https://openrouter.ai/api/v1/chat/completions",
        data=payload,
        headers={"Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json"},
        method="POST",
    )
    with urllib.request.urlopen(request, timeout=900) as response:
        body = json.load(response)
    text = body["choices"][0]["message"]["content"]
    blocks = re.findall(r"```(?:python)?\s*\n(.*?)```", text, re.DOTALL)
    source = max(blocks, key=len).strip() if blocks else text
    if "class Evolved" not in source:
        raise RuntimeError("model did not return class Evolved")
    return source

    Run the loop¶

    meta.improve() evaluates the seed, then greedily rewrites it up to trials times. Each proposal starts from the best measured program so far.

    result = meta.improve(
    seed=SEED,
    proposer=propose,
    evaluator=evaluate,
    trials=3,
)

    See what changed¶

    result.trials() is the seed plus every revision. result.best().value is the selected source. A worse rewrite stays in history; it does not become the parent of the next proposal. A timeout or crash has no score; print attempt.state for those.

    The seed should stay near 0.696. Later trials depend on the model. One recorded Claude Sonnet 5 / OpenRouter run with trials=3 is in the output comments: 0.6954 → 0.7250 → evaluation_failed → 0.7268.

    for number, attempt in enumerate(result.trials()):
    score = attempt.metrics.get("score")
    print(f"trial {number}: {score:.4f}" if isinstance(score, (int, float)) else f"trial {number}: {attempt.state}")

print("selected source:")
print(result.best().value)
# Output (one recorded Claude Sonnet 5 / OpenRouter run; later trials vary):
# trial 0: 0.6954
# trial 1: 0.7250
# trial 2: evaluation_failed
# trial 3: 0.7268

    How Meta-Evolve is used¶

    You own the task pieces. Meta-Evolve owns the loop: score the seed, ask for a rewrite, keep the best measured program, record the history.

    Component What it does here
    Artifact / seed GRG from initial_program.py, loaded as the Python source string SEED
    Proposer propose() asks Claude Sonnet 5 via OpenRouter for a new Evolved module
    Evaluator evaluate() runs score_one.py in a subprocess and returns combined_score
    Search meta.improve() uses greedy search: each proposal starts from the best measured program
    Budget trials=3 — three rewrites after the seed
    Isolation Subprocess with a 900s cap, so a hang cannot take the notebook with it
    Failures Crash, timeout, or shrink-the-text cheat has no score; search continues from the last good program
    Run result.trials() is the history; result.best().value is the selected source

    Swap the OpenRouter URL, key, and model together to use another provider. Keep the grader outside the candidate: the model rewrites Evolved, not score_one.py.

    Read findings and failures correctly¶

    The seed should print about 0.6961. That is GRG's combined_score on these five tables. The 4th digit can move with machine speed; hit rate is the stable part. A higher score means a better prefix-cache hit rate on this grader, not a measured saving on a live LLM API.

    A crash, timeout, or shrink-the-text cheat is evaluation_failed with no score. It is not a 0.0. Search continues from the last good program. result.best() is the best measured source, not the last trial. A worse rewrite stays in history.

    One recorded Claude Sonnet 5 / OpenRouter run with trials=3 was 0.6954 → 0.7250 → evaluation_failed → 0.7268. Later trials will differ. Three live trials are not a paper reproduction, and there is no held-out table split.

    Change and predict¶

    In the improve call, change trials=3 to trials=1 and rerun from that block. Predict: the seed still scores about 0.696; you get one rewrite after the seed, not three. You will not see the recorded 0.7268 third proposal. Restore trials=3 afterward.

    Change MODEL, and the matching OpenRouter URL and key together. Predict: later trial scores change; the seed score does not. Stop after the seed evaluate(SEED) print to check the wiring with no API key: predict about 0.6961.

    To adapt this to another layout algorithm, keep score_one.py and the five tables as the independent grader. Swap SEED and the proposer prompt. Do not let the candidate rewrite the grader.

    Complete supporting source¶

    The paste path above is the maintained walkthrough. ADRS_LLM_SQL_MetaEvolve.ipynb is those same cells in one file. score_one.py is the subprocess grader: it loads class Evolved, reorders five ADRS tables, rejects a candidate that drops rows or shrinks serialized text by more than 1%, and prints combined_score.

    score_one.py 
    """Score one Evolved program on ADRS llm_sql. Prints one JSON object to stdout."""
from __future__ import annotations

import importlib.util
import json
import os
import sys
import time
import traceback

PROGRAM_PATH = os.path.abspath(sys.argv[1])
TASK_DIR = os.environ["ADRS_TASK_DIR"]
sys.path.insert(0, TASK_DIR)
os.chdir(TASK_DIR)

import pandas as pd  # noqa: E402
from utils import evaluate_df_prefix_hit_cnt  # noqa: E402

TEST_FILES = [
    "datasets/movies.csv",
    "datasets/beer.csv",
    "datasets/BIRD.csv",
    "datasets/PDMX.csv",
    "datasets/products.csv",
]
COL_MERGES = [
    [["movieinfo", "movietitle", "rottentomatoeslink"]],
    [["beer/beerId", "beer/name"]],
    [["PostId", "Body"]],
    [
        ["path", "metadata"],
        ["hasmetadata", "isofficial", "isuserpublisher", "isdraft", "hasannotations", "subsetall"],
    ],
    [["product_title", "parent_asin"]],
]
REORDER_KWARGS = dict(
    early_stop=100000, distinct_value_threshold=0.7, row_stop=4, col_stop=2
)
MAX_CHAR_SHRINK = 0.01


def total_chars(frame):
    return int(frame.astype(str).map(len).to_numpy().sum())


def load_evolved(path):
    spec = importlib.util.spec_from_file_location("candidate_program", path)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module.Evolved


def main() -> int:
    try:
        evolved = load_evolved(PROGRAM_PATH)
    except Exception as error:
        print(json.dumps({"ok": False, "stage": "import", "error": f"{type(error).__name__}: {error}"}))
        return 0

    per_dataset = []
    for filename, col_merge in zip(TEST_FILES, COL_MERGES):
        frame = pd.read_csv(filename)
        before_chars = total_chars(frame)
        before_rows = len(frame)
        try:
            start = time.time()
            reordered, _ = evolved().reorder(frame, col_merge=col_merge, **REORDER_KWARGS)
            runtime = time.time() - start
        except Exception as error:
            print(json.dumps({
                "ok": False, "stage": "run", "dataset": filename,
                "error": f"{type(error).__name__}: {error}",
                "traceback": traceback.format_exc(),
            }))
            return 0
        after_chars = total_chars(reordered)
        if len(reordered) != before_rows:
            print(json.dumps({"ok": False, "stage": "invalid", "error": "row count changed"}))
            return 0
        shrink = (before_chars - after_chars) / before_chars if before_chars else 0.0
        if shrink > MAX_CHAR_SHRINK:
            print(json.dumps({
                "ok": False, "stage": "invalid",
                "error": f"serialized text shrank by {shrink * 100:.2f}%",
            }))
            return 0
        hit_count, hit_pct = evaluate_df_prefix_hit_cnt(reordered)
        per_dataset.append({
            "dataset": os.path.basename(filename),
            "hit_rate": hit_pct / 100.0,
            "runtime": runtime,
            "hit_count": hit_count,
        })

    hit_rates = [row["hit_rate"] for row in per_dataset]
    runtimes = [row["runtime"] for row in per_dataset]
    average_hit_rate = sum(hit_rates) / len(hit_rates)
    average_runtime = sum(runtimes) / len(runtimes)
    combined = 0.95 * average_hit_rate + 0.05 * (12 - min(12, average_runtime)) / 12
    print(json.dumps({
        "ok": True,
        "combined_score": combined,
        "average_hit_rate": average_hit_rate,
        "average_runtime": average_runtime,
        "per_dataset": per_dataset,
    }))
    return 0


if __name__ == "__main__":
    sys.exit(main())
