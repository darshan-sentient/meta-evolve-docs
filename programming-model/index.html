    Meta-Evolve Programming Model¶

    Status¶

    This is the canonical contract for the shipped public API available from the current package. The generated API reference owns signatures and parameter details; the guides below own task-oriented usage. Milestone 9 is shipped. The deterministic M8.1–M8.5 implementation is in the package. M8.6 is closed: the first authorized official-SDK capture failed schema validation before returning a native mutation, and a later authorized run through a second provider boundary returned complete manifests that reached native mutation decoding and the trusted successor boundary. Both captures are retained unimproved. That closes the gate's named blocker and claims nothing about statistical generalization.

    M10.1's immutable Experiment declaration and M10.2's minimal improve() callable are Shipped. M10.3's bounded @search author façade, M10.4's winner-independent Run.inspect() aggregate, M10.5's read-only durable storage, M10.6's paced and resumable Session, M10.7's optional browser, and M10.8's artifact presentation are also Shipped. The parent M10 milestone is complete as of August 14, 2026.

    Milestone 5 is complete: immutable source trees, exact patches, bounded processes, and independent command evaluation compose through the same callable path. Milestone 7 completes the cross-domain extension boundary. User-owned SDK wrappers use that path; no first-party provider adapter is shipped.

    The smallest useful mental model¶

    The smallest run names four inputs. This excerpt from the complete program uses its SEED, rewrite_prompt, and evaluate_prompt definitions. Start here explains the handwritten fixtures and run command. The prompt is a string; responses are evidence; the result is a Run:

    result = meta.improve(
    seed=SEED,
    proposer=rewrite_prompt,
    evaluator=evaluate_prompt,
    trials=2,
)

    improve() is exactly declaration sugar for the expanded path:

    task = meta.Task(evaluator=evaluate_prompt)
experiment = meta.Experiment(
    task=task,
    seed=SEED,
    proposer=rewrite_prompt,
    search=meta.Greedy(max_trials=2),
)
result = meta.run(experiment)

    Use the expansion when you need custom artifacts, objectives, satisfaction thresholds, task budgets, search, context, experience, execution mode, or a registry. It adds one declaration level:

    Task       what better means, including its independent evaluator
Seed       the initial immutable artifact
Proposer   how a successor is suggested
Search     which parent receives the next unit of work

    For 1.x compatibility, the source-compatible declaration-keyword spelling lowers through the same Experiment; new author material uses the typed form:

    result = meta.run(
    task=task,
    seed=SEED,
    proposer=rewrite_prompt,
    search=meta.Greedy(max_trials=2),
)

print(result.best().value)

    Experiment owns the eight declaration fields and defaults. Storage, mode, and a narrowing call-level budget are execution overlays on run(), never experiment fields.

    The returned Run is both the result and the query surface for aggregate inspection, trials, lineage, evidence, usage, failures, summaries, and comparisons. Safe frozen-payload presentation, direct-parent diff rules, and exact current canonical-payload-v1 bytes are specified by the browser guide.

    run() exhausts the same synchronous Session available for paced execution. Session fixes the experiment, effective budget, components, and authority at start. Each step() commits one decision or completes one owed by recovery, then returns its immutable DecisionView; it accepts no injected decision. Bootstrap is complete before Session.start() returns and is not a policy step.

    Durable storage has two independent axes: is_durable means committed facts live on durable media, while is_read_only means this handle has no commit or execution authority. Storage.durable(path) is durable and writable; Storage.read_only(path) is durable and read-only. Storage.run_version(id) returns the maximum committed event sequence, or 0 when that well-formed id has no events. The latter is a polling result, not authoritative run loading: opening a required missing run still raises RunNotFound.

    Canonical public surface¶

    The curated reference partitions shipped root exports into four tiers. Root imports are public; kernel records remain internal unless a guide explicitly describes an extension protocol.

    The constructible harness family stays under meta_evolve.harness: HarnessArtifact, HarnessMutation, MutationSurface, TextParam, PolicyParam, MutationApplication, portable repository episodes, comparison views, and export views. Only compare_harnesses, export_harness, and load_harness are root conveniences.

    The neutral MutationApplication and MutationSurface contracts live under meta_evolve.mutation; harness keeps compatibility re-exports. The data-only M9 family lives under meta_evolve.policy: PolicyArtifact, its two fixed surfaces and mutation, CandidatePolicy, portable episodes/suites, captured outcomes/evaluations, and comparison views. compare_policies is the single root convenience.

    Shipped guides¶

    • Runs and results — the callable story and query views.
    • Evaluation and budgets — objectives, evidence, usage, and typed failures.
    • Experience — no memory, pushed context, audited pull, and derivation.
    • Durability — storage, reopen, recovery, and resume.
    • SDK integration — user-owned callable wrappers and audited tools.
    • Command line — run, list, inspect, resume, compare, and browse.
    • Local run browser — optional server-rendered read-only inspection.
    • Extensions — codecs, registries, component identity, and conformance.
    • Policy evolution — trusted policy artifacts, nested capture, and held-out comparison.

    Execution profiles¶

    local accepts live Python components and defaults to isolated in-memory storage. durable-local requires durable storage plus registered, reconstructible components and records enough identity to resume honestly through either Session.resume() or resume(). The proposed distributed profile is design material, not a shipped execution mode.

    Authority and failure boundary¶

    Candidates may propose artifact content. They cannot change the evaluator, effective budget, permissions, hidden data, audit history, or promotion rule. Invalid output, proposer/evaluator failure, timeout, exhaustion, policy violation, and infrastructure failure remain typed, inspectable outcomes. A failure with no valid measurement is never ranked as a low score.

    Harness candidates receive a second, trusted check after codec encoding and before artifact creation. The built-in harness codec compares the encoded successor with its one parent and rejects changed component references, interfaces, parameter names or types as PolicyViolation; malformed and no-op transitions are InvalidOutput. Wrapper-side mutation helpers are convenience, not authority.

    M8.7.3 ships bounded list_source_paths and read_source; M8.7.4 ships canonical diff_source over exact, prior same-task/run occurrences. Successful observations may be cited in proposal derivation. M8.7.5 lets PatchProposer project a bounded committed manifest through adapter-only GitHistoryView; its callback receives meta_evolve.ports.WorkspaceSession. Experiment, root exports, run() overlays, authority, artifact identities, and the coordinator remain unchanged. This page owns the public surface; the M8.7 contract records limits and acceptance history.

    The shipped declaration is:

    meta.PatchProposer(
    edit,
    history=meta_evolve.adapters.GitHistoryView(
        max_ancestors=4,
        max_archive_members=2,
        max_chars=128_000,
    ),
)

    All bounds are required non-negative keywords. history=None preserves prior identity and behavior. In a history-enabled callback, defaulted ProposerContext.workspace contains root, the complete controlled subprocess environment, and the committed history manifest.

    Composable policy pieces¶

    The shipped presets are documented in runs and results.

    For bounded single-parent refinement, an author may declare the parent choice without receiving kernel state or constructing trials:

    @meta.search(max_trials=20)
def incumbent_refinement(search):
    return search.expand(search.incumbent or search.seed)

    The callback sees only opaque seed and optional incumbent occurrence handles, immutable declared configuration, expand(), and stop(). The adapter owns proposer binding, the unit budget, the objective and exhaustion envelope, named trial randomness, and durable explanation. Behavior-affecting configuration belongs on the decorator; closure capture is rejected because it would be invisible to run identity. Population-shaped actions and archive decisions remain on the full SearchProgram.next() extension protocol.

    Specialists and per-metric retention¶

    Specialists (meta_evolve.policies.Specialists, not a root export) retains one winning artifact occurrence per configured metric and expands a uniformly sampled metric's owner, weighting parent selection by how many metrics an occurrence owns. It is GEPA-style per-key frontier evolution, not a Pareto archive. See the search guide.

    TreeSearch and value-directed tree allocation¶

    TreeSearch (meta_evolve.policies.TreeSearch, not a root export) reconstructs one node per materialized artifact occurrence from durable history. It widens a node with a new child while child_count < ceil(sqrt(node_visits)) and otherwise descends by normalized best-descendant UCT, breaking exact ties by ascending artifact occurrence ID. See the search guide.

    Other workflows through the same loop¶

    Shipped text, source, skill-set, and custom domains use the same meta.run() boundary. Scientific and network directions are explicitly separated under Design.

    The simplicity test¶

    A common first run should remain improve(seed, proposer, evaluator, trials). A common expansion should remain one Task, one Experiment, and one meta.run(experiment) call. New internal protocols must not make that public story larger.
